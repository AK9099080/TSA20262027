### How to make edits

You have to make a branch for each feature.
Name branches based on the specific feature, bug, or task they are working on, using hyphens to separate words. It helps to include a short prefix.

# Here are some great examples:
• For new features: feature/add-login-button or feat/dark-mode
• For fixing bugs: bugfix/fix-payment-crash or fix/header-typo
• For chores/cleanup: chore/update-dependencies

## After that, you can add a description of what you did!

### Life Cycle of Branch's
Branches are meant to be short-lived. This is how the cycle works for the team:
1. Create: John creates feat/add-login-button and writes the code.
2. Review: John submits a Pull Request. It gets reviewed for compatability, gets approved, and then merges it into main(The Main Website).
3. Destroy: Once merged, that branch is deleted.
4. Repeat: Tomorrow, when John starts working on a contact form, he creates a brand new branch called feat/contact-form.
